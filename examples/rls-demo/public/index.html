This page never names the user: the demo signs you in and asserts that principal to the MCP server in the X-RLS-Principal header on every call. Every query is then rewritten server-side — each referenced table becomes (SELECT * FROM table WHERE <predicate>). Fail-closed — a table without a rule for the principal is refused. Saving rules rewrites the rules file (keeping a .bak copy) and restarts the MCP server process.
